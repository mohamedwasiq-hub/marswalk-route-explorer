# What's left

The build is complete. These steps need a person or an account, so they're yours.

## Ship

- [ ] Make the first commit. The local repo exists with all files staged, but Git has no author name or email set on this PC. Set them (`git config user.name "..."` and `git config user.email "..."`; GitHub's private noreply address keeps your real email out of public history), then `git commit -m "MarsWalk Route Explorer"`.
- [ ] Create a GitHub repository and push.
- [ ] Turn on **GitHub Pages** for the `web/` folder (Settings → Pages → GitHub Actions, or copy `web/` to `docs/`). Test the link in a signed-out browser and on a phone.
