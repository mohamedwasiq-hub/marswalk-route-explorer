# MarsWalk submission folder

**Deadline: Sunday 15 November, 11:59 PM, your Local Event's time zone (UAE time).** A saved draft does not count. You must click **Submit for Judging**.

Everything below follows the official 2026 Project Submission Guide.

## What's in this folder

| File | What it's for |
|---|---|
| `form-fields/1-project-name.txt` to `8-...txt` | The text for each field on the Project tab, in the same order as the form. Open one, copy it all and paste it in |
| `MarsWalk-demo-slides.pdf` | **Your Project Demo**: a 7-slide deck (the limit is 7). It shows the team name, member name, challenge, app screenshots, the user experience, and how NASA data makes it work |
| `demo-slides/slides.html` | The source of the deck, if you want to change a word and reprint |
| `screenshots/app-compare.jpg`, `app-inspect.jpg`, `app-plan.jpg` | Real screenshots of the app. The Project page accepts images (JPG, PNG or GIF, up to 10 MB each), so you can add these |
| `team-picture/` | The team picture: the full version with the name, and a planet-only icon for round avatar slots |

## Step by step

1. On spaceappschallenge.org, click your profile icon, then **My Team**, then the **Project** tab, then the blue **Edit** button. Turn **Lock** ON.
2. Check that the challenge is **Interplanetary Survival Guide: Martian Map**.
3. Paste each field from `form-fields/`:
   1. Project Name
   2. High-Level Project Summary
   3. Link to Project Demo
   4. Link to Final Project
   5. Detailed Project Description
   6. Use of Super Intelligence (SI). Judges don't see this field. Read it first and change anything that isn't true for you.
   7. NASA Data
   8. Space Agency Partner Data and Other References
4. Optional: add the 3 screenshots as images in the description.
5. Click **Save Progress**.
6. Open both links in a **private or incognito window** to check they work without logging in.
7. Tick **Terms and Conditions** and **Confirm All Work is Original**.
8. Click **Submit for Judging**. Wait for the banner and the confirmation message.
9. Afterwards: your participant certificate appears under **Profile → Participant Information**. Check that your **Full Name** in your profile is spelled the way you want it on the certificate.

## Rules we checked

- [x] **Demo:** a slide deck of 7 slides or fewer, in English, hosted at a public link.
- [x] **Slides include** the team name, team member names and the challenge.
- [x] **No one under 18 shown or heard:** no photos, video or voice of anyone. The slides use app screenshots only.
- [x] **All text is in English.**
- [x] **At least one NASA dataset** (HiRISE terrain and image, Viking mosaic via Mars Trek), so the project can win Global Awards.
- [x] **AI use stated in text and metadata:** app footer, page meta tag, a comment in every code file, the README, and the last slide. No AI-generated images, video or audio.
- [x] **No NASA logos** or branding in anything we made.
- [x] **Links are public.** The app and code were tested signed out.
